# 第六个 Agent：学生编程成长

## 定位

该 Agent 落在学生端，仅服务中国普通高中学生的 Python 编程启蒙、计算思维、
项目实训与计算机类专业探索。工程需求基准为 information/6.md，首期实现的是
该文档第 17 节定义的最小闭环。

## 学习闭环

~~~text
最少画像 → 五维低门槛诊断 → 16 周路线 → Python 静态检查
→ H0—H5 渐进提示 → 小型项目 → 项目陈述 → 学习证据
→ 保守能力更新 → 周报与考试期降载
~~~

静态检查不会执行学生代码。返回值固定说明 not_executed，避免把语法可解析
冒充为实际运行成功。H5 完整参考只在复盘阶段或教师授权后开放。

## 知识与数据

专用结构化目录位于 Knowledge/Agent_6/programming_learning_catalog.json，包含：

- 11 个高中阶段能力节点；
- 5 道低门槛诊断题；
- 4 个跨学科项目模板；
- H0—H5 提示阶梯；
- 项目答辩问题；
- 本地《普通高中信息技术课程标准》与需求文档的版本化引用。

没有为本实现额外下载网络材料。

MySQL 使用四张幂等创建的私有表：

- programming_learner_profiles；
- programming_learning_records；
- programming_learning_events；
- programming_skill_states。

单条证据触发的掌握度上调不超过 0.12、下调不超过 0.08；环境问题和主动求助
不作为负向能力证据。每次更新保留来源、独立度、推理、验证、提示等级和置信度。

## 学生端验收

登录学生账号后访问：

~~~text
http://127.0.0.1:3000/?view=programming
~~~

依次可验收画像与考试期降载、基础诊断、代码教练、项目实训和项目答辩。

# 1. 核心结论

## 1.1 2026年全国新课标Ⅰ卷适用地区

截至2026年高考公开试卷使用情况，全国新课标Ⅰ卷主要适用于以下11个省份：

```text
浙江
山东
江苏
河北
福建
湖北
湖南
广东
江西
安徽
河南
```

这些省份的共同点是：

```text
语文、数学、外语：
主要使用教育部教育考试院统一命制的全国新课标Ⅰ卷

物理、历史、化学、生物学、思想政治、地理：
根据各省考试模式和省级命题安排组织考试
```

因此，知识库不能建立成：

```text
全国Ⅰ卷九学科统一题库
```

而应该建立成：

```text
全国Ⅰ卷语文题库
全国Ⅰ卷数学题库
全国Ⅰ卷外语题库
+
浙江选考科目题库
山东等级考试题库
江苏选择性考试题库
河北选择性考试题库
福建选择性考试题库
湖北选择性考试题库
湖南选择性考试题库
广东选择性考试题库
江西选择性考试题库
安徽选择性考试题库
河南选择性考试题库
```

---

## 1.2 教材出版社不能由“全国Ⅰ卷”直接确定

“参加全国Ⅰ卷”不等于“统一使用同一个出版社的全部教材”。

可以比较确定的是：

| 学科 | 教材性质 | 主要出版单位 |
|---|---|---|
| 语文 | 国家统编高中教材 | 人民教育出版社 |
| 思想政治 | 国家统编高中教材 | 人民教育出版社 |
| 历史 | 国家统编高中教材 | 人民教育出版社 |

其余学科通常存在多个教育部审定版本：

```text
数学
英语
物理
化学
生物学
地理
```

这些学科使用哪个版本，通常由省、市、县、学校根据国家教学用书目录和当地教材选用结果确定。

因此，同一个省内不同地区、不同学校，也可能出现不同教材版本。

---

## 1.3 关于教材PDF

课程标准、考试政策、教材目录等文件通常存在官方公开PDF，可以直接作为知识库来源。

完整教科书通常受著作权保护。国家智慧教育平台和出版社可能提供在线阅读，但：

```text
可以在线阅读
≠
允许批量下载PDF
≠
允许OCR后用于商业知识库
≠
允许重新分发教材内容
```

生产环境应当：

1. 使用官方电子教材入口核验版本；
2. 向出版社、学校或资源授权方取得合法文件；
3. 保存授权范围、用途、有效期和版权信息；
4. 不使用盗版网站、网盘泄露版或绕过访问限制的方法。

## 2.2 浙江的特殊性

浙江采用“3+3”模式。

统一高考必考科目：

```text
语文
数学
外语
```

选考科目从以下7门中选择3门：

```text
思想政治
历史
地理
物理
化学
生物学
技术
```

其中“技术”通常涉及：

```text
信息技术
通用技术
```

这意味着，如果系统支持浙江考生，仅建设传统九学科知识库还不够，还应增加：

```text
浙江信息技术知识库
浙江通用技术知识库
浙江技术选考真题库
```

浙江省教育考试院政策说明：

[浙江省高考招生相关政策问答](https://www.zjzs.net/art/2022/6/19/art_159_7037.html)

统一考试科目：

## 2.4 其余9省的共同结构

江苏、河北、福建、湖北、湖南、广东、江西、安徽、河南主要采用“3+1+2”模式。

```text
“3”：
语文、数学、外语

“1”：
物理、历史二选一

“2”：
思想政治、地理、化学、生物学四选二
```

知识库中应记录学生的真实选科组合，例如：

```json
{
  "province": "广东",
  "exam_mode": "3+1+2",
  "first_choice_subject": "物理",
  "second_choice_subjects": ["化学", "生物学"],
  "subject_combination": "物化生"
}
```

# 3. 各地区考试模式和考试科目

## 3.1 全国Ⅰ卷统一命题科目

全国新课标Ⅰ卷的核心统一科目是：

```text
语文
数学
外语
```

外语科目不能永远直接写成“英语”。

根据考生报名和当地考试安排，外语可能包括：

```text
英语
日语
俄语
德语
法语
西班牙语
```

项目第一阶段可以优先建设英语知识库，但用户画像必须保存：

```json
{
  "foreign_language": "英语"
}
```

否则日语考生提问时可能错误检索英语教材。

---

## 3.2 选择性考试科目

“3+1+2”地区通常包括：

```text
首选科目：
物理、历史二选一

再选科目：
思想政治、地理、化学、生物学四选二
```

“3+3”地区通常从若干等级考试科目中选择3门。

这些科目的：

- 正式试卷；
- 答案；
- 评分参考；
- 考试时间；
- 赋分规则；
- 题型结构；

均应按省份管理，不能只按“全国Ⅰ卷”管理。

# 4. 全国Ⅰ卷与教材版本之间的关系

## 4.1 高考试卷依据课程标准，不绑定单一教材

高考命题以国家课程方案、课程标准和考试评价要求为主要依据。

因此：

```text
同一份全国Ⅰ卷
可以对应多个经过国家审定的教材版本
```

例如数学考生可能使用：

```text
人教A版
人教B版
北师大版
苏教版
湘教版
```

但参加的是同一份全国Ⅰ卷数学试卷。

RAG系统必须把以下概念分开：

```text
考试卷型
教材版本
学生所在省份
学生所在学校
知识点标准
```

---

## 4.2 三门国家统编高中教材

高中阶段可以优先确定的三科为：

### 语文

```text
编写性质：国家统编
出版单位：人民教育出版社
```

### 思想政治

```text
编写性质：国家统编
出版单位：人民教育出版社
```

### 历史

```text
编写性质：国家统编
出版单位：人民教育出版社
```

这三科可以作为全国Ⅰ卷11省的公共教材基础库，但地方考试题、教学进度和补充资源仍需按省份管理。

---

## 4.3 多版本学科

以下学科不能只根据“全国Ⅰ卷”确定出版社：

```text
数学
英语
物理
化学
生物学
地理
```

正确做法是向用户或学校收集：

```text
教材封面照片
版权页照片
出版社
版次
册次
ISBN
学校所在地
当前年级
```

首次使用系统时建议让学生选择：

```json
{
  "subject": "数学",
  "publisher": "人民教育出版社",
  "edition": "A版",
  "volume": "选择性必修第一册",
  "isbn": "以教材版权页为准"
}
```

## 6.3 为什么不直接提供所有教科书PDF直链

完整教科书属于受著作权保护的出版物。官方通常采用：

```text
网页阅读器
登录后阅读
学校授权平台
数字教材客户端
出版社授权文件
```

而不是公开、长期稳定的单册PDF直链。

因此，对于知识库建设：

```text
官方在线链接用于核验
授权PDF或授权数字文件用于解析
```

不应使用搜索引擎找到的非官方“教材PDF下载站”。

# 11. 教材PDF的合法获取方式

## 11.1 推荐顺序

### 第一种：出版社授权

向对应出版社申请：

```text
数字教材授权
内容API
机构使用许可
教育平台合作许可
可用于OCR或Embedding的源文件
```

这是商业知识库最稳妥的方法。

---

### 第二种：学校或教育机构授权

如果项目与学校合作，可由学校提供：

```text
学校合法采购的数字教材
当地实际使用教材清单
教材版权页和ISBN
教师用书
校内教学资源
```

授权文件中必须明确：

```text
是否允许机器解析
是否允许建立向量索引
是否允许向学生展示原文
是否允许商用
是否允许长期保存
```

---

### 第三种：官方公开电子教材

可使用国家智慧教育平台和出版社网站进行：

```text
版本核验
人工阅读
章节映射
目录核对
```

但是否允许自动抓取和Embedding，应以平台服务条款和授权为准。

---

### 第四种：购买正版纸质教材后扫描

购买正版教材不自动获得数字复制和商业使用权。

仅限内部研究时也应：

- 限制访问；
- 不公开传播；
- 不向用户输出大段原文；
- 评估著作权例外是否适用；
- 商业化前另行取得许可。

---

## 11.2 明确不建议

```text
盗版PDF下载站
未经授权的网盘资源
绕过登录或加密下载
破解在线阅读器
删除平台访问控制
将整本教材公开提供下载
```

这些做法存在版权、合规、数据安全和项目下线风险。

# 13. 不同省份知识库的路由设计

## 13.1 语文、数学、外语

用户来自11省之一时，可以共同检索：

```text
全国Ⅰ卷真题库
国家课程标准库
对应教材版本库
```

但仍应携带省份，因为作文教学、听力安排、教材版本和学校进度可能不同。

---

## 13.2 选择性考试科目

必须按照省份过滤。

例如江苏学生问化学题：

```json
{
  "province": "江苏",
  "subject": "化学",
  "collections": [
    "national_curriculum_standard",
    "student_textbook_su_education",
    "jiangsu_chemistry_exam",
    "jiangsu_scoring_reference"
  ]
}
```

不能自动检索：

```text
山东化学等级考试评分规则
广东化学选择性考试答案
浙江化学选考赋分政策
```

## 13.3 教材版本过滤

```json
{
  "subject": "英语",
  "publisher": "译林出版社",
  "edition": "译林版",
  "volume": "选择性必修第二册"
}
```

如果学生没有提供版本：

1. 先根据教材封面识别；
2. 读取版权页和ISBN；
3. 无法确认时只检索课程标准和公共知识；
4. 不要默认所有学生都使用人教版。

# 14. 第一阶段最小可用资料包

如果暂时无法一次建设11省全学科知识库，建议按以下顺序实施。

## 阶段一：公共权威库

直接下载并入库：

```text
普通高中课程方案
```

```text
江苏历史历年选择性考试

江苏评分参考
江苏教学用书目录
```

```text

省级评分规则
当地教材目录
学校教材版本
```

# 15. 最终结论

对于全国新课标Ⅰ卷知识库，正确的资料结构是：

```text
全国共同层：
课程标准
+ 高考评价体系
+ 全国Ⅰ卷语文
+ 全国Ⅰ卷数学
+ 全国Ⅰ卷外语

省级差异层：
物理
+ 历史
+ 化学
+ 生物学
+ 思想政治
+ 地理
+ 赋分政策
+ 评分规则

教材版本层：
国家统编语文、思想政治、历史
+ 各地实际选用的数学、英语、物理、化学、生物学、地理教材

学校和学生层：
学校教材版本
+ 选科组合
+ 教学进度
+ 错题
+ 作答记录
```

最需要避免的三种错误是：

```text
错误一：
认为全国Ⅰ卷包含九科统一试卷

错误二：
认为全国Ⅰ卷11省全部使用同一套出版社教材

错误三：
从非官方渠道批量下载教材PDF并直接用于商业RAG
```

第一版项目可以使用：

```text
官方课程标准PDF
+ 全国Ⅰ卷语数外真题
+ 一个目标省份的选考真题
+ 人教版教材作为原型基线
```

但生产版必须进一步做到：

```text
按省份检索
按教材版本检索
按考试年份检索
按来源权威等级排序
按版权授权范围控制内容
```

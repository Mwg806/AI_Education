# 手机号无密码认证部署说明

学生使用“学号 + 手机号 + 短信验证码”，教师使用“教师账号/工号 + 手机号 + 短信验证码”。同一手机号可绑定多个学生或教师账号，手机号不设唯一索引。

## 服务端配置

将 `.env.example` 中的手机号认证变量复制到本地 `.env`，并填写 AccessKey。密钥只能由 Python 服务端读取，禁止使用 `VITE_` 前缀或提交到 Git。

```dotenv
AI_EDUCATION_PHONE_AUTH_ENABLED=true
ALIBABA_CLOUD_ACCESS_KEY_ID=
ALIBABA_CLOUD_ACCESS_KEY_SECRET=
AI_EDUCATION_PHONE_AUTH_SCHEME_NAME=问鹿用户认证
AI_EDUCATION_PHONE_AUTH_SIGN_NAME=速通互联验证码
AI_EDUCATION_PHONE_AUTH_TEMPLATE_CODE=100001
```

执行迁移：`python scripts/apply_migrations.py`

迁移会清除旧账号的密码哈希。旧账号的 `phone_e164` 默认为空，无法通过新流程登录。管理员应核验学生或教师身份后直接补录手机号，禁止提供仅凭账号 ID 即可绑定手机号的公开接口。

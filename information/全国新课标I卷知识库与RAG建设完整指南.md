# 全国新课标Ⅰ卷高中全学科知识库与 RAG 建设指南

> 适用场景：面向使用全国新课标Ⅰ卷（通常也称“新高考Ⅰ卷”“全国一卷”）地区高中生的作业辅导、错题诊断、知识讲解、真题分析、学习规划与备考问答系统。  
> 建设目标：将课程标准、教材、真题、答案、评分规则、官方评析和学生学习数据转化为可检索、可追溯、可更新、可评测的知识库，为大模型提供可靠证据。

---

## 1. 项目结论

对于全国新课标Ⅰ卷考生，知识库不能简单理解为“收集九个学科的全国一卷 PDF，然后全部放进一个向量数据库”。

更合理的建设方式是：

```text
国家课程标准
+ 中国高考评价体系
+ 全国新课标Ⅰ卷语文、数学、外语资料
+ 学生所在省份的选择性考试资料
+ 学生实际使用的教材与教师用书
+ 标准答案与评分规则
+ 高质量教学解析
+ 学生个人错题和作答记录
```

其中必须注意：

- 语文、数学、外语通常使用全国统一命题试卷；
- 物理、历史、化学、生物学、思想政治、地理等选择性考试科目，需要根据学生所在省份建立对应题库；
- 不同省份的选考科目试卷结构、设问习惯、评分依据和教材版本可能不同；
- 因此，系统首次采集学生信息时，至少要获取所在省份、考试年份、选科组合和教材版本。

推荐的用户画像字段如下：

```json
{
  "province": "江苏",
  "exam_year": 2027,
  "exam_mode": "3+1+2",
  "national_paper_type": "全国新课标Ⅰ卷",
  "selected_subjects": ["物理", "化学", "生物学"],
  "textbook_versions": {
    "chinese": "人教版",
    "mathematics": "人教A版",
    "english": "译林版",
    "physics": "人教版",
    "chemistry": "苏教版",
    "biology": "人教版"
  }
}
```

# 2. 知识库建设目标

知识库不是单纯保存 PDF，而是要支持以下业务能力：

1. 判断知识点是否属于高中课程和高考范围；
2. 准确解释概念、公式、定理、实验和学科方法；
3. 检索全国新课标Ⅰ卷或目标省份历年真题；
4. 根据标准答案和评分细则判断学生能得多少分；
5. 分析学生错误属于知识、审题、计算、推理还是表达问题；
6. 提供同知识点、同题型、同难度的相似题；
7. 回答时显示文件名、年份、题号、页码等依据；
8. 当知识库证据不足时，明确提示，不让模型编造答案；
9. 支持后续增加学习规划 Agent、作业辅导 Agent、错题 Agent、测评 Agent 等节点；
10. 支持按年份、地区、教材版本和政策变化持续更新。

知识库建设后的标准检索链路建议为：

```text
用户问题
  ↓
识别省份、学科、年级、教材版本、考试年份
  ↓
判断问题类型
  ├── 知识讲解
  ├── 作业解题
  ├── 真题查询
  ├── 作文批改
  ├── 实验分析
  └── 评分诊断
  ↓
选择对应知识库
  ↓
元数据过滤
  ↓
向量检索 + 关键词检索
  ↓
Reranker 重排
  ↓
证据质量判断
  ↓
大模型生成答案
  ↓
计算或规则工具复核
  ↓
输出来源、页码、题号和可信度
```

# 3. 必须准备的 PDF 材料

## 3.1 P0：最高优先级权威材料

P0 材料决定知识范围、命题依据和地区适配，必须优先收集。

### 3.1.1 普通高中课程方案

建议准备：

```text
《普通高中课程方案（2017年版2020年修订）》
```

用途：

- 确定高中课程总体结构；
- 区分必修、选择性必修和选修；
- 判断内容是否属于高中教学范围；
- 防止 RAG 引入大学或竞赛内容，造成超纲回答。

### 3.1.2 九学科普通高中课程标准

建议准备以下 PDF：

```text
《普通高中语文课程标准（2017年版2020年修订）》
《普通高中数学课程标准（2017年版2020年修订）》
《普通高中英语课程标准（2017年版2020年修订）》
《普通高中物理课程标准（2017年版2020年修订）》
《普通高中化学课程标准（2017年版2020年修订）》
《普通高中生物学课程标准（2017年版2020年修订）》
《普通高中思想政治课程标准（2017年版2020年修订）》
《普通高中历史课程标准（2017年版2020年修订）》
《普通高中地理课程标准（2017年版2020年修订）》
```

课程标准应重点抽取：

- 学科核心素养；
- 课程目标；
- 内容要求；
- 学业要求；
- 学业质量水平；
- 教学提示；
- 学业水平考试与高考相关要求；
- 必修与选择性必修模块关系；
- 推荐实验、活动和探究任务。

### 3.1.3 中国高考评价体系材料

建议准备：

```text
《中国高考评价体系》
《中国高考评价体系说明》
教育部教育考试院发布的高考内容改革、命题原则和试题评析
```

用途：

- 建立“必备知识—关键能力—学科素养—核心价值”标签；
- 分析题目为何体现基础性、综合性、应用性或创新性；
- 支持 Agent 解释全国新课标Ⅰ卷的命题特点；
- 避免只按“题型套路”进行机械辅导。

### 3.1.4 目标省份高考实施方案

每个支持的省份都应准备：

```text
目标省份普通高校招生考试实施方案
目标省份当年高考报名办法或考试问答
目标省份考试科目与计分规则说明
目标省份选择性考试实施办法
目标省份再选科目等级赋分办法
目标省份考试时间、科目组合和招生政策说明
```

例如系统服务江苏学生时，应单独建立江苏政策资料库，不能只依赖“全国一卷”标签。

建议记录：

```json
{
  "province": "江苏",
  "effective_year": 2026,
  "exam_mode": "3+1+2",
  "national_subjects": ["语文", "数学", "外语"],
  "provincial_subjects": ["物理", "历史", "化学", "生物学", "思想政治", "地理"],
  "score_rule": "以当年省级官方文件为准",
  "source_file": "江苏省2026年普通高校招生考试相关文件.pdf"
}
```

## 3.2 P0：全国新课标Ⅰ卷真题材料

### 3.2.1 需要准备的年份

第一阶段建议至少准备最近 6 年资料；条件允许时，可扩展至 8～10 年。

每一年、每个学科应尽量准备完整资料包：

```text
原始试卷 PDF
参考答案 PDF
官方试题评析 PDF 或网页归档
可核验的详细解析 PDF
评分参考或评分细则 PDF
答题卡样式 PDF
听力音频与听力原文（外语）
```

### 3.2.2 全国统一命题科目

优先准备：

```text
全国新课标Ⅰ卷语文
全国新课标Ⅰ卷数学
全国卷外语或对应新课标卷外语
```

文件不能只标记为“全国卷”，还应明确：

- 年份；
- 学科；
- 卷型；
- 正式卷、适应性测试或模拟卷；
- 试卷、答案、解析或评分参考；
- 来源级别。

推荐文件名：

```text
2025_NATIONAL_NEW_CURRICULUM_I_CHINESE_PAPER_OFFICIAL.pdf
2025_NATIONAL_NEW_CURRICULUM_I_CHINESE_ANSWER_OFFICIAL.pdf
2025_NATIONAL_NEW_CURRICULUM_I_CHINESE_ANALYSIS_AUTHORIZED.pdf

2025_NATIONAL_NEW_CURRICULUM_I_MATH_PAPER_OFFICIAL.pdf
2025_NATIONAL_NEW_CURRICULUM_I_MATH_ANSWER_OFFICIAL.pdf

2025_NATIONAL_NEW_CURRICULUM_I_ENGLISH_PAPER_OFFICIAL.pdf
2025_NATIONAL_NEW_CURRICULUM_I_ENGLISH_LISTENING_TRANSCRIPT.pdf
```

也可以使用中文命名，但必须统一：

```text
2025_全国新课标I卷_数学_试卷_官方.pdf
2025_全国新课标I卷_数学_参考答案_官方.pdf
2025_全国新课标I卷_数学_详细解析_授权资料.pdf
```

不要使用以下模糊命名：

```text
数学卷.pdf
答案最新版.pdf
高考真题1.pdf
最终版.pdf
新建PDF文档.pdf
```

## 3.3 P0：省级选择性考试真题

物理、历史、化学、生物学、思想政治、地理不能只建立统一的“全国一卷题库”。

应按照省份组织：

```text
江苏省普通高中学业水平选择性考试物理
江苏省普通高中学业水平选择性考试历史
江苏省普通高中学业水平选择性考试化学
江苏省普通高中学业水平选择性考试生物学
江苏省普通高中学业水平选择性考试思想政治
江苏省普通高中学业水平选择性考试地理
```

如果系统同时服务多个省份，应分别保存：

```text
provincial_papers/
├── 江苏/
├── 山东/
├── 广东/
├── 福建/
├── 湖北/
├── 湖南/
├── 河北/
└── 其他目标省份/
```

每个省份至少准备：

```text
历年正式试卷
正式参考答案
可核验解析
评分参考
官方试题评析
当年试卷结构说明
```

检索时必须同时过滤：

```text
province
subject
year
paper_type
document_type
```

否则可能出现：

> 江苏学生提问化学题，系统却检索到山东卷评分方式。

## 3.4 P1：正式教材 PDF

真题负责回答“怎么考”，教材负责回答“知识应该怎样准确讲”。

每个学科应准备学生正在使用的正式教材，包括：

```text
必修教材
选择性必修教材
教材目录
教材附录
实验与探究活动
课后习题
教材内例题
```

教材必须保留以下信息：

- 出版社；
- 学科；
- 版本；
- 册次；
- 版次或修订年份；
- 章节；
- 页码；
- 必修或选择性必修；
- 适用省份或学校；
- 授权状态。

示例：

```json
{
  "publisher": "人民教育出版社",
  "subject": "数学",
  "edition": "A版",
  "volume": "选择性必修第一册",
  "module_type": "选择性必修",
  "chapter": "空间向量与立体几何",
  "section": "空间向量基本定理",
  "page": 87
}
```

禁止把不同教材版本的同名章节直接混合而不做标注。

---

## 3.5 P1：教师教学用书 PDF

教师教学用书对作业辅导 Agent 的价值很高，因为其中通常包含：

- 教学目标；
- 教学重难点；
- 概念形成过程；
- 例题讲解建议；
- 学生常见困难；
- 易错点；
- 章节衔接关系；
- 实验教学建议；
- 习题参考答案；
- 教学活动设计。

建议与教材建立一一对应关系：

```text
教材：
人教A版_数学_选择性必修第一册.pdf

教师用书：
人教A版_数学_选择性必修第一册_教师教学用书.pdf
```

元数据中增加：

```json
{
  "document_type": "教师教学用书",
  "linked_textbook_id": "TEXTBOOK-MATH-PEP-A-XBX1"
}
```

> 注意：教材、教师用书和商业教辅通常涉及版权。用于商业系统前应取得合法授权，并保留授权范围、有效期和使用方式记录。

## 3.6 P1：标准答案、评分参考与规范作答材料

这是实现“过程评分”和“失分诊断”的核心资料。

建议收集：

```text
数学解答题分步骤得分点
语文现代文阅读参考答案
语文古诗文阅读评分参考
语文作文评分标准
英语应用文写作评分标准
英语读后续写评分标准
物理计算题评分步骤
物理、化学、生物实验题评分点
政治、历史、地理材料题评分参考
可接受的等价表达
典型失分案例
```

评分知识应独立结构化，不要只作为解析中的一段文本。

示例：

```json
{
  "question_id": "2025-NCI-MATH-Q19",
  "total_score": 17,
  "scoring_points": [
    {
      "step_id": "S1",
      "score": 2,
      "condition": "正确写出目标函数或等价关系",
      "required_expression": "以原评分参考为准"
    },
    {
      "step_id": "S2",
      "score": 3,
      "condition": "正确求导并确定定义域"
    }
  ],
  "acceptable_alternatives": [],
  "common_deductions": [
    "缺少定义域说明",
    "分类讨论不完整",
    "只给结论无推导"
  ]
}
```

## 3.7 P1：官方试题评析

官方试题评析应单独建立知识库，因为它主要回答：

- 本年度命题重点是什么；
- 试题如何落实课程标准；
- 如何考查关键能力；
- 哪些题体现情境化、开放性或综合性；
- 对日常教学和备考有什么导向。

建议按以下粒度切分：

```text
年度
→ 学科
→ 命题总体评价
→ 具体考查方向
→ 典型题例
→ 教学建议
```

不要将一整篇年度评析作为一个大 Chunk。

## 3.8 P2：高质量教学解析与专题讲义

可以收集：

```text
学校教研组讲义
名师专题讲义
题型归纳资料
一题多解资料
实验专题资料
作文讲评资料
高频易错点资料
章节复习资料
```

但必须设置比官方材料更低的知识权重，并记录：

```json
{
  "authority_level": "B",
  "source_type": "学校教研组",
  "review_status": "已由学科教师审核",
  "reviewer": "内部教师编号",
  "review_date": "2026-07-01"
}
```

网络博客、论坛答案、自媒体解析不能直接作为高可信知识。

## 3.9 P2：高质量模拟卷

模拟卷可补充题量，但不能与正式高考真题同权。

必须区分：

```text
高考正式卷
官方适应性测试
省级联考
地市模拟
名校模拟
普通教辅题
模型自动生成题
```

推荐权重：

| 资料类型 | 建议权重 |
|---|---:|
| 国家或省级正式高考试卷 | 1.00 |
| 官方适应性测试 | 0.95 |
| 省级教育考试机构评析 | 0.95 |
| 权威教材和课程标准 | 1.00 |
| 经审核的学校教研资料 | 0.80 |
| 高质量模拟卷 | 0.65 |
| 普通商业教辅 | 0.50 |
| 未审核网络解析 | 0.20 |
| 模型自动生成内容 | 不进入正式知识库，除非人工审核 |

## 3.10 P2：学生错题与真实作答

用于个性化辅导时，需要准备：

```text
学生原始题目
学生原始答案
教师批改
失分位置
错误原因
订正答案
相似错题
后续练习结果
掌握度变化
```

错因标签建议统一为：

```text
KNOWLEDGE_GAP       知识缺失
CONCEPT_CONFUSION   概念混淆
CONDITION_OMISSION  条件遗漏
READING_ERROR       审题错误
FORMULA_MISUSE      公式误用
CALCULATION_ERROR   计算错误
LOGIC_GAP           推理跳步
EXPRESSION_ERROR    表达不规范
EXPERIMENT_ERROR    实验设计或操作错误
STRATEGY_ERROR      解题策略不当
TIME_MANAGEMENT     时间分配问题
```

学生数据必须与公共知识库隔离，并进行权限控制和脱敏处理。

# 4. 九学科 PDF 专项清单

## 4.1 语文

建议准备：

```text
语文课程标准
全国新课标Ⅰ卷历年语文试卷
参考答案和评分参考
官方语文试题评析
正式语文教材
教师教学用书
现代文阅读原文及出处
文言文原文、注释和可靠译文
古诗词原文、注释、背景和鉴赏资料
课程标准推荐背诵篇目
语言文字运用专题资料
作文评分标准
高质量作文样例及评分说明
学生作文批改案例
```

语文知识库应特别保存：

- 阅读材料原文和段落编号；
- 题目和文本证据句；
- 主观题参考答案要点；
- 可接受的等价表达；
- 作文材料、任务要求、立意边界；
- 作文评分维度；
- 文言实词、虚词、句式和文化常识；
- 诗歌作者、时代和作品出处。

语文切块不能把“阅读原文”和“问题”完全割裂，应通过 `passage_id` 建立关联。

## 4.2 数学

建议准备：

```text
数学课程标准
全国新课标Ⅰ卷历年数学试卷
标准答案
逐步解析
评分参考
教材定义、定理和公式
```

```text
+ 解题步骤
+ 评分点
```


# 7. 文档清单 Manifest

建议建立 `document_manifest.csv`，每个 PDF 一行。

字段示例：

```csv
document_id,file_name,sha256,document_title,document_type,authority_level,country,province,paper_type,subject,year,publisher,edition,volume,source_org,source_url,download_date,language,page_count,is_scanned,has_formula,has_table,has_figure,ocr_required,copyright_status,review_status,version,effective_date,expiry_date,parent_document_id,notes
```

关键字段解释：

| 字段 | 含义 |
|---|---|
| `document_id` | 全局唯一编号 |
| `sha256` | 文件哈希，用于去重和版本控制 |
| `document_type` | 课程标准、试卷、答案、评分参考、教材等 |
| `authority_level` | A、B、C 等来源等级 |
| `province` | 选择性考试材料必须填写 |
| `paper_type` | 全国新课标Ⅰ卷、省级选择性考试、模拟卷等 |
| `is_scanned` | 是否为扫描 PDF |
| `ocr_required` | 是否需要 OCR |
| `copyright_status` | 官方公开、已授权、仅内部使用、待确认 |
| `review_status` | 待审核、已审核、退回 |
| `effective_date` | 政策和时政资料生效日期 |
| `expiry_date` | 失效日期 |
| `parent_document_id` | 试卷与答案、教材与教师用书的关联 |

# 8. PDF 入库前质量检查

每个文件进入解析流程前，检查：

## 8.1 来源检查

- 是否来自教育部、教育考试机构、出版社或授权渠道；
- 是否有明确标题、年份和版本；
- 是否为正式卷、适应性测试或模拟卷；
- 是否存在篡改、缺页、错页；
- 是否有更权威版本。

## 8.2 完整性检查

- 页数是否完整；
- 题目是否缺失；
- 图表是否清晰；
- 答案和解析是否对应同一试卷；
- 听力材料是否包含原文；
- 页码是否连续；
- 是否存在水印遮挡。

## 8.3 重复检查

使用 SHA-256 哈希：

```bash
sha256sum 文件名.pdf
```

同时进行文本相似度去重，避免：

- 同一份 PDF 改名后重复入库；
- 同一试卷存在多个带不同水印的版本；
- “解析版”中重复嵌入整份原题。

## 8.4 版权检查

每份材料标记：

```text
OFFICIAL_PUBLIC      官方公开
LICENSED             已获授权
INTERNAL_ONLY        仅限内部
UNKNOWN              权利状态待确认
REJECTED             不可使用
```

# 9. PDF 分类与解析策略

PDF 应先分类，再选择解析方式。

## 9.1 文本型 PDF

特征：

- 可以复制文字；
- 文本顺序基本正确；
- 公式和表格较少。

推荐流程：

```text
PDF
→ PyMuPDF / pdfplumber 提取
→ 标题与段落恢复
→ 页眉页脚删除
→ Markdown
→ JSON
```

## 9.2 扫描型 PDF

特征：

- 页面是图片；
- 无法复制文字；
- 可能存在倾斜、阴影和低分辨率。

推荐流程：

```text
PDF 页面渲染
→ 图像纠偏
→ 去噪和增强
→ OCR
→ 版面分析
→ 阅读顺序恢复
→ 人工抽检
```

可使用：

```text
PaddleOCR
MinerU
OCRmyPDF
RapidOCR
```

## 9.3 复杂版面 PDF

包括：

- 双栏试卷；
- 大量公式；
- 表格；
- 化学结构式；
- 地图和统计图；
- 图文混排；
- 题目跨页。

推荐使用支持版面分析的工具：

```text
MinerU
Docling
Unstructured
```

必要时结合多模态模型识别页面结构，但模型识别结果必须保留原页图用于复核。

## 9.4 公式密集 PDF

数学、物理和化学资料不能只保留 OCR 纯文本。

建议同时保存：

```json
{
  "formula_latex": "\\frac{-b\\pm\\sqrt{b^2-4ac}}{2a}",
  "formula_text": "一元二次方程求根公式",
  "formula_image_path": "images/doc123/page12/formula03.png",
  "page": 12,
  "bbox": [100, 220, 460, 310]
}
```

公式解析失败时，不要用错误公式覆盖原图，应标记：

```text
FORMULA_REVIEW_REQUIRED
```

## 9.5 图像密集 PDF

地理、历史、物理实验和生物图像需要：

- 保存原图；
- 记录图像页码和坐标；
- 生成图像描述；
- 与题目 ID 绑定；
- 检索结果返回原图或裁剪图。

# 13. 知识切块设计

## 13.1 不要只按固定字符切块

以下方式不适合作为唯一方案：

```python
chunk_size = 500
chunk_overlap = 50
```

因为它可能：

- 把题干和条件切开；
- 把小问和答案切开；
- 把公式分成两段；
- 把文章和阅读题分开；
- 把评分点拆散；
- 把表格标题和表格内容拆开。

应采用“结构优先、长度辅助”的语义切块。

---

## 13.2 课程标准切块

推荐粒度：

```text
学科
→ 模块
→ 主题
→ 内容要求
→ 学业要求
→ 教学提示
```

每个 Chunk 建议包含一个完整要求，约 300～1000 个中文字符。

---

## 13.3 教材切块

推荐粒度：

```text
章
→ 节
→ 知识点
→ 定义
→ 定理
→ 例题
→ 习题
```

建议：

- 一个定义单独成块；
- 一个定理及其条件、结论和注意事项成块；
- 一道例题连同解析成块；
- 相关知识通过 `parent_id` 和 `related_ids` 建立关系。

---

## 13.4 真题切块

每道题应形成一个主对象，而不是简单字符切割。

推荐建立多个关联 Chunk：

```text
Question Chunk
Solution Chunk
Scoring Chunk
Error Analysis Chunk
```

它们共享同一个 `question_id`。

### 客观题

一个 Chunk 可包含：

```text
题干
+ 选项
+ 正确答案
+ 解析
+ 干扰项分析
```

### 主观题

建议：

```text
父 Chunk：完整题干和全部小问
子 Chunk 1：第（1）问及解析
子 Chunk 2：第（2）问及解析
子 Chunk 3：评分细则
子 Chunk 4：常见错误
```

检索时先命中子 Chunk，再回溯父 Chunk。

---

## 13.5 阅读材料切块

语文和英语阅读应采用父子索引：

```text
父文档：完整文章
子 Chunk：段落
子 Chunk：题目
子 Chunk：答案解析
```

通过 `passage_id` 关联，禁止把题目与文章完全失联。

---

## 13.6 评分规则切块

评分规则不宜与普通解析混在一起。

推荐：

```json
{
  "chunk_type": "SCORING_RULE",
  "question_id": "2025-NCI-MATH-Q19",
  "scoring_dimension": "步骤得分",
  "content": "……"
}
```

---

## 13.7 Chunk 长度建议

以下仅作为起始参数，最终要通过检索评测调整：

| 内容类型 | 建议长度 |
|---|---:|
| 课程标准要求 | 300～800 字 |
| 教材概念和定理 | 300～1000 字 |
| 客观题及解析 | 一题一块 |
| 主观题题干 | 一题一个父块 |
| 主观题小问解析 | 一问一块 |
| 作文评分标准 | 一个评分维度一块 |
| 阅读文章 | 父文档保留全文，段落作为子块 |
| 教学评析 | 一个观点或一个典型题例一块 |
| 政策文件 | 一个条款或主题一块 |

`chunk_overlap` 只用于自然段切分，题目结构不应依靠重叠修复。

# 16. 向量化与索引设计

## 16.1 不建议只使用单一向量索引

推荐：

```text
Dense Vector Search
+
BM25 Keyword Search
+
Metadata Filter
+
Reranker
```

各部分作用：

- 向量检索：查找语义相近内容；
- BM25：精确匹配题号、年份、术语、公式名称；
- 元数据过滤：限制省份、学科、教材版本和试卷类型；
- Reranker：重新判断候选片段与问题的相关性。

## 16.2 Embedding 文本

不要只向量化正文，可拼接关键元数据：

```text
标题：2025年全国新课标Ⅰ卷数学第19题
学科：数学
题型：解答题
知识点：导数、函数单调性
正文：……
```

但省份、年份、权限等精确字段仍应作为数据库过滤条件，不能只写进文本。

## 16.3 推荐数据库

原型阶段：

```text
FAISS
Chroma
```

生产阶段可考虑：

```text
Qdrant
Milvus
Elasticsearch / OpenSearch
PostgreSQL + pgvector
```

选择依据：

- 数据规模；
- 并发量；
- 是否需要混合检索；
- 元数据过滤能力；
- 运维能力；
- 多租户隔离；
- 备份和审计要求。

# 28. 最终实施原则

全国新课标Ⅰ卷知识库建设应遵循以下原则：

```text
先权威，后扩量；
先结构，后向量；
先区分省份，后做全学科；
先保证题目、答案、解析配对，再追求题量；
先建立元数据和知识树，再进行 Embedding；
先完成检索评测，再接入大模型生成；
RAG 提供依据，工具负责验算，审核节点负责兜底。
```

最终推荐方案为：

```text
权威课程与考试标准
+
全国新课标Ⅰ卷语数外真题
+
目标省份选择性考试真题
+
教材与教师教学用书
+
标准答案与评分细则
+
结构化题目数据库
+
混合检索与 Reranker
+
学科计算工具
+
答案复核 Agent
+
来源引用和知识库版本管理
```

这套架构不仅能提高大模型回答准确度，也能保证系统知道：

- 当前回答依据哪份资料；
- 该资料适用于哪个省份和年份；
- 这是一道正式高考题还是模拟题；
- 学生的步骤能够获得多少分；
- 当前证据是否足够；
- 哪些内容属于知识库事实，哪些属于模型推理。

## 1. 项目概况

本项目面向全国新课标Ⅰ卷高中学习场景，已经完成两个可独立工作、又能通过统一协议协同运行的教育智能体：

1. 个性化学习规划智能体：根据地区考试政策、选科组合、教材版本、当前章节、成绩目标、知识掌握度和可用时间生成学习计划。
2. 作业辅导智能体：接收文字题目、图片题目或图文组合，围绕学生当前步骤提供启发式辅导，并利用本地“五年高考三年模拟”题库更新检索依据。

项目已经建立统一智能体接口、全局状态、消息协议、调度层和结果聚合机制，当前实现可以支持 6 个以上智能体继续接入，不需要重构核心调度框架。

## 3. 个性化学习规划智能体

### 3.1 已完成功能

- 支持全国新课标Ⅰ卷范围内的 11 个地区配置。
- 同时支持“3+1+2”和“3+3”两类选科模式。
- 支持语文、数学、英语、物理、化学、生物学、思想政治、历史、地理、技术共 10 类规划科目。
- 根据本地教材 PDF 目录提供教材版本、册次和章节选择。
- 支持分数目标、目标时间、每周时间、工作日时间、周末时间、基础掌握度和综合应用掌握度录入。
- 生成知识画像、时间画像、阶段目标、本周任务、机动缓冲及计划校验结果。
- 支持计划确认、版本管理、练习反馈、局部调整和重新规划。
- 计划未通过校验时禁止错误发布，并显示具体未通过项目。

### 3.2 当前任务类型及中文展示

| 内部任务类型 | 用户界面名称 | 作用 |
|---|---|---|
| `concept_learning` | 概念学习 | 理解核心概念、适用条件和基本表示 |
| `foundation_practice` | 基础巩固 | 使用基础题巩固定义、公式和基本方法 |
| `variant_practice` | 变式训练 | 改变题目条件或问法，训练方法迁移 |
| `spaced_review` | 间隔复习 | 根据遗忘风险复习关键知识 |
| `timed_training` | 限时训练 | 建立时间分配和解题稳定性证据 |
| `stage_assessment` | 阶段测评 | 检查阶段学习效果，为下一阶段提供独立证据 |

### 3.3 已修复的重要问题

#### “3+3”地区计划不能发布

原因为计划服务的二次校验错误地把“3+3”地区按照“3+1+2”的首选、再选规则校验，导致浙江、山东等地区的合法选科仍被判定失败。

现已按考试配置分别校验：

- “3+3”：从允许科目中选择 3 门。
- “3+1+2”：首选科目 1 门、再选科目 2 门。

#### 缺少限时训练和阶段测评

原因为单科规划的有效时间被错误分摊给语文、数学、英语和选考科目，导致当前目标科目的预算不足，排期时过滤了限时训练及阶段测评。

现已改为：单科目标只为当前目标科目分配计划预算；多目标场景则按照实际目标科目分配。重新生成计划后会明确包含间隔复习、限时训练和阶段测评。

#### 内部英文和知识点 ID 直接展示

前端已经加入统一中文映射，任务卡、优先补齐、知识画像和练习反馈下拉框不再直接显示内部英文枚举或教材哈希 ID。

例如：

- `TB-MATH-V-4A34584FBC9B-C01_foundation`
  - 用户界面显示为：数学 · 苏教版 · 选择性必修第一册 · 第1章《直线与方程》· 基础掌握。
- `TB-MATH-V-4A34584FBC9B-C01_application`
  - 用户界面显示为：数学 · 苏教版 · 选择性必修第一册 · 第1章《直线与方程》· 综合应用。

其中：

- `TB` 表示教材目录资源。
- `MATH` 表示数学科目。
- `V-4A34584FBC9B` 是对应教材册次的稳定标识。
- `C01` 表示该册目录中的第 1 章。
- `foundation` 和 `application` 分别表示基础掌握和综合应用两个画像维度，并不是虚构的新章节。

## 4. 作业辅导智能体

### 4.1 已完成功能

- 采用 LangGraph 构建完整辅导流程。
- 支持纯文字、纯图片、图片加文字三种输入形式。
- 支持题目读取、OCR 低置信度确认、分步提示、当前步骤检查、知识回顾、完整作答提交和同类训练入口。
- 用户发送的文字和图片都会保留并展示在对话消息中。
- 题目录入与分步辅导已经合并为一个连续对话框。
- 每轮根据题干、本轮消息和本轮学生作答重新判断意图。
- 每轮使用“题干 + 当前消息 + 当前作答”重新检索题库依据。
- 题库答案和解析使用安全隔离策略，不向学生端泄露内部答案通道。
- 没有唯一题号与评分答案映射时，会明确标记不确定，不伪造正确或错误结论。
- 完成作答后可以生成知识证据事件，供规划智能体后续更新知识画像。

### 4.2 智能反馈改进

原版本无论用户输入什么，都会重复“你的完整作答已提交并进入过程校验”，没有读取具体内容。

现已改为内容感知反馈：

- 引用学生本轮提交的具体步骤。
- 根据科目和题目关键词识别当前考点。
- 给出与当前考点对应的方法提示和检查点。
- 区分提示请求、步骤检查、知识回顾和完整作答提交。
- 不再使用固定回复代替实际分析。

例如数学导数与单调性题目会提示检查定义域、导函数、临界点及导数符号，而不会对所有题目返回同一段话。

## 7. Vue 前端建设

### 7.1 整体设计

- 使用 Vue 3、TypeScript 和 Vite 开发，不再使用单体 HTML 页面。
- 蓝白配色，保持简洁、直观和可操作性。
- 具有登录页面，登录时录入学生基础信息。
- 登录后进入双智能体学习中心。
- 支持桌面端和移动端响应式布局。

### 7.2 主要页面

- 规划中心：录入地区、选科、目标科目、教材、章节、成绩目标和时间。

- 知识画像：展示当前掌握度、置信度和遗忘风险。
- 练习反馈：将真实完成结果反馈给规划智能体。
- 作业辅导：统一图文对话、题库依据和分步辅导。

### 7.3 交互优化

- 左侧边栏可以随时收起和展开。
- 折叠状态保存在浏览器本地，下次打开继续保持。
- 移动端使用抽屉式侧边栏。
- 计划未通过时显示具体失败约束。
- 任务名称、教材章节、知识画像和优先缺口均使用中文可读名称。
- 作业图片在发送前可预览，发送后继续显示在对话记录中。

## 13. 当前限制与注意事项

1. 已经生成的旧计划采用版本化管理，不会被系统静默修改。应用规划修复后，需要返回规划中心重新生成计划。
2. 当前运行中的后端健康状态显示 `llm_enabled: false`，因此使用本地题库检索和内容感知兜底逻辑；如需外部大模型深度推理，需要安全注入模型环境变量并重启服务。
3. 线上静态站点无法直接访问局域网内的 `127.0.0.1:8000`，真实后端调用应通过服务器页面或安全公网反向代理完成。
4. 当前工作区未启用 Sites 匿名互联网发布，线上地址仍受授权账号限制。
5. 用户曾在对话中明文提供 API Key。密钥未写入本总结，也不应提交到 Git；建议对已暴露密钥进行轮换，并仅通过服务器环境变量或密钥管理系统配置。
6. 题库命中元数据不等于唯一题号和标准答案映射。没有可靠映射时，辅导智能体不会虚构正误结论。
